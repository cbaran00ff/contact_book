 <!-- Phone Contact Book -->

Консольное приложение для управления контактами на Python.

## 🚀 Возможности

- ✅ Добавление контактов с валидацией номера
- 🔍 Поиск контакта по имени
- ✏️ Редактирование номера телефона
- 🗑️ Удаление контактов
- 💾 Хранение данных в словаре

## 📋 Требования

- Python 3.8+
